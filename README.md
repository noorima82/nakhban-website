# مدرسه کنکور نخبان | NOKNBAN

سایت استاتیک مدرسه کنکور نخبان — دو صفحه، بدون فریم‌ورک:

| صفحه | فایل | توضیح |
|---|---|---|
| صفحه اصلی | `index.html` | هدر، بنر تخفیف با شمارش معکوس زنده، کارت‌های «سوپر پک تکنیکی» و «تک دوره»، بنر پشتیبانی |
| ثبت درخواست | `submit-request.html` | فرم چندمرحله‌ای ثبت درخواست با اعتبارسنجی و مودال موفقیت |

## ساختار
```
index.html
submit-request.html
assets/          ← تصاویر (کارت‌ها، بنرها، لوگو)
```

## اجرای محلی
همین پوشه را باز کنید و `index.html` را در مرورگر اجرا کنید — بدون build.
